# Portfolio source

The homepage and 50 static project stories use buildless HTML, CSS and JavaScript. All project text comes from the supplied project inventory and inspected repository records. The original interactive apps, certificates and legacy routes remain available.

`site.css` defines the visual system. `site.js` provides project filters, scroll reveals, a scroll progress line and decorative canvas motion. The motion control and reduced-motion preference can stop decorative animation.

Project source and measured results are not invented. Illustrative SVGs are labeled as concept visuals. Original project screenshots and animations link to their public repositories.
