03 / ENGINEERING NOTES

Look a
little closer.

Live tuning

Four potentiometers provide target and gain inputs. Arduino Uno drives an L298N output sequence.

A useful control distinction

The program counts commanded steps. It does not read measured shaft position, so it cannot detect missed steps.

Next measurement

Independent shaft feedback would let the demonstrator measure physical tracking error.
