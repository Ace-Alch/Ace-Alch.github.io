Sounder

Turn the frequency control and see how the AVR timer drives the output pin.

50 Hz requested, 276.55 Hz calculated.

The firmware stores the timer compare value in a 16-bit register. At low frequencies the value exceeds the register capacity. The signal above uses the value the register actually holds.

Host run of the original compare calculation and interrupt handler. The browser audio is a preview. Firmware source
