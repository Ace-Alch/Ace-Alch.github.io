Bluetooth HID Proxy / PROJECT INFO

Bridge input across interfaces.

An embedded Linux experiment to forward USB mouse input over Bluetooth.

Embedded LinuxBluetoothUSB HIDESP32
Open demo

What I built

Explored USB HID input, Bluetooth forwarding, and device reconnection.

Built an interactive view of reports, loss, and latency.

Goals reached

Made the report path and connection state visible in a browser demonstration.

Provided controls to inspect packet delivery under changing conditions.

Scope and limits

The web page simulates the data path; it does not provide a Bluetooth connection to the visitor’s devices.
