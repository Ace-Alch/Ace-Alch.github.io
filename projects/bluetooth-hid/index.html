Model, controls & engineering details

Trace the path

Motion produces signed relative deltas. The bridge packs a four-byte illustrative mouse report: buttons, X, Y, wheel. Negative deltas use two’s complement. Delivery moves the target cursor.

Experiment with transport

Increase delay to separate input from output. Increase deterministic loss to see missing movement. Disconnect the link and packets are dropped. Reset clears the queue, counters and cursor positions.

Protocol boundary

This browser does not read USB devices or act as a Bluetooth peripheral. Report format depends on an actual HID descriptor. Timers demonstrate configured delay, not measured hardware latency. Loss uses a repeatable pattern, not a radio model.
