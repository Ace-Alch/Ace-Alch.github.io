# Engineering Portfolio Website: setup

## Current entry point

1. Recover the original project files from the existing repository.
2. Identify its main entry point and required tool versions.
3. Copy configuration from a token-free example.
4. Run one documented baseline case. Record its inputs and outputs.
5. Compare the observed output with the original report before marking the setup verified.

No install or run command is supplied without an identified source manifest or build entry point.

## Required records

- Editable source location
- Build provenance
- Performance and accessibility tests

## Reproducibility record

Record the source commit, operating system, tool versions, dependencies, input files, configuration and command. Store the output separately from the expected result. Mark any manual step.
